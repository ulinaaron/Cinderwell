# Cinderwell Media Folders — Client Guide

## Organizing Your Media

Media folders let you group uploads by topic, project, or client — like folders on your computer.

## Creating a Folder

1. Go to **Media → Library**
2. Select the **+** button beside Folders
3. Type a name and click **Create**

Use a folder's **More** menu to add a nested folder, rename it, or delete it. Deleting a folder does not delete its media; those files become Unfiled.

## Moving Media to a Folder

1. Select one or more files in the grid.
2. Drag the selection onto a folder in the sidebar.
3. Drop files on **Unfiled** to remove their folder assignment.

Files uploaded while a folder is open are filed there automatically. If no folder is open, the configured default folder is used.

## Finding Media

- Select a folder to show only the media filed there.
- Type in **Search folders** to find a folder in a large tree.
- Use the folder selector in a media picker when choosing images inside a page or block.
- Switch to list view and use the **All folders** dropdown when you need WordPress's table tools.

## Color Tags

Use **Advanced folder management** in Cinderwell → Media Folders to assign a color tag. The color appears on that folder in the Media Library tree.
