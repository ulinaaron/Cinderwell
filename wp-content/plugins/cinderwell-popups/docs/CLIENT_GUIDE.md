# Client guide

## Good uses

- Newsletter signup forms
- Short announcements
- Contact or quote forms
- Video and supporting content

Avoid placing essential information only inside a popup. Visitors should still be able to complete the primary page task if they dismiss it.

## Testing

Use a private browser window when testing frequency. Confirm that the close button, Escape key, and the shaded area all close the popup. On a narrow screen the popup becomes full screen.

If an automatic popup does not appear, confirm it is published, its current URL or page matches the display rules, it is not excluded, and browser storage has been cleared for frequency testing.
