Accessible modals built with Cinderwell blocks and opened automatically or by a button.

== Description ==

Build popup content in the block editor, target automatic popups by URL, post type, or individual content, and connect manual popups to Cinderwell Button blocks or the standalone Popup Trigger block.

Frequency controls support once per session, once per year, and every visit. Modal behavior includes focus trapping, Escape and overlay dismissal, focus restoration, scroll locking, reduced-motion support, and full-screen mobile presentation.

== Installation ==

1. Install and activate Cinderwell.
2. Upload and activate Cinderwell Popups.
3. Open Cinderwell > Popups and create a popup.
