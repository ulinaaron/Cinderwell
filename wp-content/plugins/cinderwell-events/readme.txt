One-time and multi-session event publishing for Cinderwell sites.

== Description ==

Events are one-time by default. Editors can optionally enable Multiple sessions when the same Event happens more than once. Each date remains authoritative and independently editable.

Version 0.1.0 includes Event content, categories, Session management, chronological public listings, block templates, REST endpoints, and PHP query helpers.
