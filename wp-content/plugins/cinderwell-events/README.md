# Cinderwell Events

Cinderwell Events keeps one-time publishing simple while supporting authoritative Sessions when an Event happens more than once:

- **Event:** title, description, image, categories, and public page.
- **Session:** one independently editable start/end occurrence.

Create Events under the top-level **Events** menu. New Events use **One-time** mode with a simple date and time. Choose **Multiple sessions** only when the Event happens more than once; the full Session manager then supports adding, editing, and deleting dates. Schedule changes save immediately in the WordPress site timezone.

The add-on provides a chronological Event archive and an **Upcoming Sessions** block. One-time dates and Sessions share the same query contract. Each listed date links to its parent Event, so a multi-session Event may appear several times.
