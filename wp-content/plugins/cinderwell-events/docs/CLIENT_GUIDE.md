# Client guide

## One-time Events and Sessions

New Events are **One-time** by default. Add the Event's date and time in the Event Schedule panel.

Choose **Multiple sessions** only when the same Event happens more than once. Add a Session for every actual occurrence. The original one-time date becomes the first Session, so it does not need to be entered again.

If one meeting moves, edit only that Session. Do not duplicate the Event or change the other Sessions.

## All-day Sessions

Enable **All day** when visitors only need dates. The end date shown in the manager is inclusive, so a one-day Session uses the same start and end date.

## Publishing

Draft and trashed Events never appear in public Session listings. A published Event with no upcoming Sessions remains available at its direct URL but is omitted from the upcoming archive.
