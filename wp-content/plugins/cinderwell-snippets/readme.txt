Safely manage PHP, JavaScript, CSS, and HTML snippets for Cinderwell sites.

== Description ==

Snippet Manager provides administrator-only code editing, curated run locations,
page and audience conditions, priorities, shortcodes, Safe Mode, fatal-error
auto-disable, and versioned JSON import/export.

PHP snippets have the same power as plugin code. Only install or author code you
trust. Set CINDERWELL_SNIPPETS_SAFE_MODE to true in wp-config.php to bypass all
snippet execution during recovery.

== Installation ==

1. Install and activate Cinderwell.
2. Upload and activate Cinderwell Snippet Manager.
3. Open Cinderwell > Snippets.
