Accessible search metadata, explainable content analysis, social previews, schema, and native sitemap controls for Cinderwell sites.

== Description ==

Cinderwell SEO is a deliberately focused SEO add-on. It uses WordPress native titles, robots directives, canonicals, and XML sitemaps while adding client-friendly controls and an explainable SEO-readiness score.

When a recognized SEO plugin is active, Cinderwell SEO enters safe standby and emits no public SEO output.

== Installation ==

1. Install and activate Cinderwell 0.1.86 or newer.
2. Activate Cinderwell SEO.
3. Configure it under Cinderwell → SEO.
